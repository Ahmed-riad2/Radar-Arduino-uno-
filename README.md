To display a visual "radar screen" on your computer, you need a program that can listen to the Serial data your Arduino is sending (the angle and distance) and draw it on the screen.

The most popular and easiest tool for this is Processing. It is a sister project to Arduino, and its coding environment looks almost identical.

Here is the complete guide and code to get your radar window running.

Step 1: Download and Setup Processing
Go to processing.org/download and download the software for your operating system.
https://processing.org/download
Extract the files and open the Processing IDE.
